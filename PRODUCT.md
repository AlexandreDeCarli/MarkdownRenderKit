# Product

## Register

product

## Users
Developers, technical writers, researchers, and professionals who need to convert Markdown text into elegant, presentation-ready PDF documents or HTML pages directly in the browser, without dealing with complex command-line tools or bloated PDF editors.

## Product Purpose
A high-performance, beautiful Markdown editor and preview tool featuring real-time rendering, syntax highlighting, Mermaid diagrams, and a premium print engine for high-quality, customized PDF exports.

## Brand Personality
- **Sophisticated**: clean design, balanced layout, premium micro-interactions.
- **Accurate**: real-time rendering, exact PDF print-margins matching the live preview.
- **Minimalist**: focusing on content creation, removing clutter, but offering power-user configurations.

## Anti-references
- Clunky traditional Markdown editors with 90s-style UI borders.
- Slow, laggy web editors that freeze on large Mermaid diagrams or long code segments.
- Hard-to-read interfaces with low-contrast text or chaotic colors.

## Design Principles
- **Preview Fidelity**: what the user sees in the editor side-by-side preview must match the exported PDF document precisely.
- **Seamless Flow**: all configuration changes (fonts, sizes, margins) apply immediately without reloading.
- **Typographic Integrity**: default font sizes, heights, and weights are tuned for extreme readability in physical print and digital displays.

## Accessibility & Inclusion
- Clear contrast ratios matching WCAG AA standards.
- High-contrast visual focus indicators for keyboard accessibility.
- Optimized layouts supporting different screen resolutions and zoom levels.
